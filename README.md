# 🏡This is a *clone* of Satismoment! by Hapiga Studio (2D game).

## 👀Preview: 📄[Docs](https://docs.google.com/spreadsheets/d/1w1TJIBbDCAZtlQtwbz91id1Pqh5M3DYBiav8j7GkVaI/edit?usp=sharing) | ▶️[Demo](https://markdownlivepreview.com/)

## 🧩About the Original Game
Satismoment is a cozy puzzle game designed to provide ultimate relaxation and satisfaction.

## ✨Features:
1. 🎯 **Project Scope & Mechanics**:
    * 185 Levels Cloned
    * 6 core mechanics: Unboxing, Finding, Organizing, Connecting, Sorting, and Jigsaw Puzzles.
    * Google AdMob integration for testing
    * Hint Booster for each level
    * Short Gameplay Loops: Levels are designed for quick sessions, ranging from 10 seconds to 3 minutes.
2. 💾**Data Management**:
    * Game Data: Scriptable Object.
    * User Data: Saved as JSON and PlayerPrefs.
3. 📈**Performance Optimizations**:
    * Sprite Atlas: < 20 draw calls.
    * Addressable: load/unload level prefab
