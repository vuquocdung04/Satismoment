## Features:
### 🎯 Project Scope & Mechanics:
    1. 185 Levels Cloned
    2. 6 core mechanics: Unboxing, Finding, Organizing, Connecting, Sorting, and Jigsaw Puzzles.
    3. Google AdMob integration for testing
    4. Hint Booster for each level
    5. Short Gameplay Loops: Levels are designed for quick sessions, ranging from 10 seconds to 3 minutes.
### 💾Data Management:
    1. Game Data: Scriptable Object.
    2. User Data: Saved as JSON and PlayerPrefs.
### 📈Performance Optimizations:
    1. Sprite Atlas: < 20 draw calls.
    2. Addressable: load/unload level prefab
